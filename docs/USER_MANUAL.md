# WatchApi 使用说明

WatchApi 用来管理多个 OpenAI 兼容接口，并让 Codex、Claude Code、OpenCode 等 Agent 始终运行在当前可用、权重最高的接口上。软件会自动探测接口、切换可用线路、续航任务、记录终端输出，也可以配置本地聚合代理和供应商库。

这份手册面向日常使用，不包含开发和源码说明。

## 1. 启动软件

打开便携目录中的 `watchapi-gui.exe`。

常用目录：

- `Configs`：保存工作区下的配置文件。
- `ProxyConfigs`：保存聚合代理配置和生成文件。
- `logs`：保存运行日志。
- `prompt-library.json`：保存提示词库。

如果关闭窗口，软件会询问是否进入系统托盘。进入托盘只是隐藏界面，后台任务会继续运行；需要完全退出时，在托盘菜单选择退出。

## 2. 基本概念

### 工作区

工作区是一组配置文件的容器，通常对应一个项目目录。左侧树的最高层就是工作区。

工作区右键可进行：

- 新建配置项
- 编辑工作区参数
- 置顶工作区
- 打开工作区目录
- 移除工作区

工作区参数是给多个配置复用的公共参数。编辑配置时，可以点击“继承工作区配置”，把工作区里的公共运行参数复制到当前配置。

### 配置

一个配置表示一套 Agent 运行方案，包括：

- 使用哪个工作目录
- 使用 Codex / Claude Code / OpenCode / generic
- 自动续航提示词
- 探测、超时、容错、卡死判断参数
- 当前配置引用哪些供应商接口

配置右键可进行：

- 编辑配置
- 当前配置另存为
- 设置显示名
- 移除
- 自动运行开关
- 置顶配置
- 强制新对话
- 打开日志目录

### 供应商

供应商是接口库，保存真实接口的 URL、Key、模型、权重、保护层等信息。配置文件本身只引用供应商，不需要每个配置重复维护一份完整接口。

顶部点击“供应商”进入供应商库。

### 聚合代理

聚合代理用于把多个上游 URL、多批 Key、模型路由统一成一个本地接口。配置中的供应商可以直接引用这个本地代理地址。

顶部点击“代理”进入 LiteLLM / 内置智能代理配置页。

## 3. 快速上手

1. 打开 `watchapi-gui.exe`。
2. 左侧点击添加工作区，选择你的项目目录。
3. 在工作区右侧点击加号，新建配置。
4. 在配置编辑器中填写配置名称、Agent 类型、提示词和运行参数。
5. 到“供应商”页添加接口，填写 URL、Key、模型和权重。
6. 回到运行页，在接口表里把需要的供应商添加到当前配置。
7. 点击当前配置卡片右上角的启动按钮。

启动后，WatchApi 会探测接口，选择可用且权重最高的接口运行 Agent。

## 4. 运行页操作

运行页是日常使用最多的页面。

### 启动、暂停、继续

当前配置卡片右上角的主按钮会根据状态变化：

- 未运行：点击后启动当前配置。
- 运行中且自动续航开启：点击后暂停自动续航。
- 运行中且自动续航暂停：点击后继续自动续航，并触发下一轮续航。

暂停自动续航不会关闭终端，也不会停止正在运行的任务。暂停后，软件不会因为长时间无输出、错误码、网络波动等自动重启终端。

### 全部启动

顶部“操作”菜单中的“全部启动”会遍历左侧所有配置，相当于对每个配置执行一次启动或继续：

- 未运行的配置会启动。
- 已运行但暂停的配置会继续。
- 每个配置会解除 `auto_paused`，并触发一次续航检查。
- 切回对应配置后，按钮状态会显示为运行中的暂停按钮。

### 按权重重新探测

探测按钮会让当前运行态重新按权重检查接口。适合在你修好接口、换代理、换 Key 后手动刷新可用性。

### 续航提示词

运行页可以直接编辑“续航提示词”。保存后，后续自动续航会使用最新内容。

### 终端输入

需要临时补充任务说明时，直接在运行页终端里输入即可；GUI 会把内容写入当前 PTY，不再提供单独输入行。

## 5. 配置编辑器

配置编辑器包含公共参数和会话绑定。

常用字段：

- 配置名称：左侧显示名称和默认文件名。
- Agent 类型：`codex`、`claude-code`、`opencode` 或 `generic`。
- Agent 命令：自定义 Agent 启动命令。
- 探测间隔：运行循环的基础 tick 间隔。
- 健康探测间隔：当前低权重接口运行时，多久检查高权重接口是否恢复。
- 请求超时：HTTP 探测请求最长等待时间。
- 空闲秒数：终端无输出多久后认为可能可以继续。
- Session 静默：当前轮 session 文件尾部多久没有新增内容后，认为任务可能卡住。
- 卡死阈值：连续多少次卡死才切换。
- 请求容错次数：接口请求连续失败多少次才切走。
- 污染冷却：接口污染或不可用后多久再尝试。
- 初始提示词：新会话第一次启动时发送。
- 续航提示词：后续自动续航时发送。

Codex 会话启动时，WatchApi 会在隔离的 `CODEX_HOME` 中强制写入 TUI 状态栏配置，并通过启动参数再次覆盖，状态栏包含模型与推理强度、剩余上下文、当前目录、Git 分支和已用上下文。

配置保存后，如果当前配置正在运行，软件只会落盘，不会自动重启当前任务。改动会在下次启动或手动重启后完整生效。

## 6. 工作区参数继承

如果多个配置需要同一套续航、探测、容错参数，可以使用工作区参数。

用法：

1. 左侧工作区右键，选择“编辑工作区参数”。
2. 设置公共运行参数和提示词。
3. 保存工作区参数。
4. 打开某个配置的编辑器。
5. 点击“继承工作区配置”。
6. 保存配置。

继承只会复制公共运行参数，不会覆盖配置名称、工作目录、Agent 身份、接口列表和供应商库。

## 7. 供应商库

顶部点击“供应商”进入供应商库。

每个供应商一般需要配置：

- 名称：配置引用用的名字。
- Base URL：接口地址，例如 `https://example.com/v1`。
- API Key：接口 Key。
- 模型：实际请求的模型名。
- 权重：数值越大优先级越高。
- reasoning effort / service tier：Codex 相关模型参数。
- 本地保护层：可选，用于过滤、脱敏、审计和重试。默认不预置过滤关键词，只有手动填写过滤关键词并开启“改写成功响应”时才会删除成功响应文本。“改写请求”单独控制 temperature、max tokens、降级模型、防注入前缀和系统提示词追加这些请求侧改写；关闭后请求侧原样转发，但 invalid_encrypted_content 修复仍由独立开关控制。检测模式可选 `hybrid` 或 `keywords_only`；`keywords_only` 只按过滤关键词和失败关键词判断，适合只想拦截自定义污染词的场景。保护层有独立污染冷却，默认 120 秒；“替代直接污染判断”默认开启，取消后全局污染关键词会作为兜底继续判断。

保存供应商库后，配置引用这些供应商即可。添加供应商后，运行页接口表可以把它加入当前配置。

## 8. 聚合代理

聚合代理适合多 Key、多上游、多模型路由场景。

常见流程：

1. 顶部点击“代理”。
2. 新增代理实例。
3. 设置本地端口和代理 Key。
4. 添加上游 URL。
5. 添加 Key 文件，支持 txt/csv。
6. 配置模型路由。
7. 启动代理。
8. 到供应商页，把供应商连接方式切到聚合代理路由。

内置智能代理会根据成功率、失败、冷却、延迟等信息自动排行和避让。LiteLLM 模式可以生成 LiteLLM 配置文件。

## 9. 自动续航和卡死处理

WatchApi 会观察 Agent 的终端输出和 session 文件，判断是否可以发送下一轮续航提示词。

核心规则：

- Agent 正在 Working 时，不会强行塞提示词。
- 如果 session 文件长期没有新增内容，超过“Session 静默”后会认为可能卡住。
- 自动续航暂停时，不会因为卡死、错误码、网络波动自动重启终端。
- 遇到接口冷却提示时，会等待冷却时间后再尝试。
- 当前接口不可用时，会按权重切到下一个可用接口。

如果你只是想让当前任务停在原地，不要重启终端，点击暂停即可。

## 10. 系统托盘

关闭窗口时可以选择进入托盘。

进入托盘后：

- 运行中的配置继续运行。
- 自动续航状态保持不变。
- 代理继续运行。
- 可以从托盘菜单恢复窗口或退出软件。

如果托盘不可用，软件会降级为最小化到任务栏。

## 11. 常见问题

### 接口一直失败怎么办？

先看接口表的状态码和错误信息。常见原因包括 Key 错误、额度不足、限流、代理不可用、Base URL 写错。

可以手动点击“按权重重新探测”。如果接口处于冷却中，需要等待冷却时间结束。

### 522 是什么？

通常表示服务器或上游网关连接失败，常见于上游服务不可达、代理链路异常、Cloudflare 或类似网关无法连到源站。它不一定是你的 Key 错。

### 暂停后为什么任务还在跑？

暂停只是不再自动续航和自动切换，不会杀掉当前终端里的 Agent。正在执行的任务会继续，除非你发送 Esc 或手动关闭。

### 保存配置会不会重启当前任务？

不会。运行中的当前配置保存后只会落盘，当前终端不会自动重启。

### 为什么 GUI exe 覆盖失败？

如果软件正在运行，Windows 会占用 `watchapi-gui.exe`。构建新版本时可以先生成 `watchapi-gui.new.exe`，关闭软件后再改名覆盖。

### 什么时候用工作区参数？

当你有多个配置，但希望它们共用同一套续航、探测、容错、提示词参数时使用。每个配置仍然可以单独保存自己的接口和身份信息。

## 12. 推荐使用习惯

- 每个项目建一个工作区。
- 每种运行策略建一个配置，比如“主线”“低成本”“高质量”。
- 供应商集中在供应商库维护，不要每个配置重复填接口。
- 常用续航提示词保存到提示词库。
- 离开电脑前，用“全部启动”批量启动或继续需要无人值守的配置。
- 想暂时保留现场时，用暂停，不要停止运行态。
